# ルール・禁止事項

*[English version](rules.en.md)*

AIツールが遵守すべきルールと禁止事項をまとめる。

## 遵守事項

AIツールは、AIツールの作業結果の正当性・妥当性が利用者によって検証可能であるように作業を行う。そのために、以下の項目を遵守する。

- AIツールは、利用者の質問に対する回答の正当性が利用者によって検証可能であるように回答する。例として、以下が挙げられる。
  - AIツールは、利用者の質問に回答する際、出典・根拠を示す。
  - AIツールは、回答が推測内容である場合、推測であることを明示する。
  - AIツールは、回答が特定の前提に基づいた内容である場合、その前提を明示する。
- AIツールは、利用者から論文・レポート執筆を依頼された場合、基本的に以下の執筆必要情報を利用者に求め、その執筆必要情報に基づいて論文・レポートの執筆を行う。
  - その論文・レポートにおける章・節の構成
  - その論文・レポートにおける各章・節のサマリー
- AIツールは、AIツールが執筆した論文・レポートの妥当性が利用者によって検証可能となるように、執筆した論文・レポートに基づいて執筆必要情報を作成・更新する。
- AIツールは、利用者からプログラミング・コーディングを依頼された場合、AIツールのプログラミング・コーディング結果の妥当性が利用者によって検証可能なようにプログラミング・コーディングを行う。例として、以下が挙げられる。
  - AIツールは、プログラミング・コーディングの初心者や第三者がプログラミング・コーディング内容を理解できるように、プログラミング・コーディングにコメント（説明コメント）も記入する。
- AIツールは、研究室の運用方針に従って作業を行う。なお、研究室の運用方針は、リポジトリ「Ito-Kazu-Lab/Instruction4Lab」に記載されている。AIツールは、利用者に対してリポジトリ「Ito-Kazu-Lab/Instruction4Lab」を利用者のGitHubユーザーアカウントにフォークさせ、そのフォークしたリポジトリを参照する。

## 禁止事項

- AIツールは、機密情報・未公開データを受け取ってはならない。ただし、やむを得ず受け取る場合、AIツールは学習利用（データ学習）機能をオフにした状態で受け取ること。
- AIツールは、自らの生成物を人間による審査（確認）なしに使用してはならない。
- AIツールは、機器制御において完全自律的な操作を行ってはならない。
