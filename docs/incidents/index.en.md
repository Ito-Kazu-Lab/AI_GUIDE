## Recording policy

- Name files `YYYY-MM-DD-short-english-slug.md` (English versions use the same name with `.en.md`).
- Each record should include: a summary (date, status), the symptom, the investigation, the conclusion/cause (keeping confirmed facts separate from inference), a workaround, and related information.
- The Japanese version is the source of truth; keep the English version in sync with it.
- When adding a new incident, add one row to this index as well.
