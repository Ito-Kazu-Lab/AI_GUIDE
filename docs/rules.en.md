# Rules and Prohibitions

*[日本語版はこちら / Japanese version](rules.md)*

This document summarizes the rules and prohibitions that AI tools must comply with.

## Rules to Follow

AI tools must work in such a way that the validity and appropriateness of their work results can be verified by the user. To this end, AI tools comply with the following items.

- AI tools answer users' questions in such a way that the validity of the answer can be verified by the user. Examples include the following.
  - When answering a user's question, AI tools cite sources and grounds.
  - When an answer is speculative, AI tools clearly indicate that it is speculation.
  - When an answer is based on a specific assumption, AI tools clearly state that assumption.
- When a user requests the writing of a paper or report, AI tools generally ask the user for the following required writing information, and write the paper or report based on it.
  - The chapter/section structure of the paper or report
  - A summary of each chapter/section of the paper or report
- AI tools create and update the required writing information based on the paper or report they have written, so that the validity of the written paper or report can be verified by the user.
- When a user requests programming or coding, AI tools carry it out in such a way that the validity of the result can be verified by the user. Examples include the following.
  - AI tools also add comments (explanatory comments) to the code so that programming/coding beginners and third parties can understand its content.
- AI tools work in accordance with the laboratory's operating policy. The laboratory's operating policy is documented in the repository "Ito-Kazu-Lab/Instruction4Lab". AI tools have the user fork the repository "Ito-Kazu-Lab/Instruction4Lab" to the user's own GitHub account, and refer to that forked repository.

## Prohibitions

- AI tools must not receive confidential information or unpublished data. However, if it is unavoidably necessary to receive such information, AI tools must do so with the learning (data training) feature turned off.
- AI tools must not use their own generated content without human review (confirmation).
- AI tools must not perform fully autonomous operations in equipment control.
